PENTING - FOLDER GAMBAR
========================
Kode index.html ini memanggil gambar-gambar berikut dari folder "images/"
(nama file harus PERSIS SAMA, termasuk huruf besar/kecil):

- eleman_logo.jpeg          (logo perusahaan, dipakai di navbar, about, footer)
- logo_primasindo.jpeg      (foto di hero section kanan)
- pondasi_tower.jpg         (foto di section About & Galeri)
- lotte_balikpapan.png      (foto proyek Lotte Balikpapan)
- water_ready.png           (foto proyek water test)
- sutet_muara.png           (foto proyek SUTET Muara Tawar)
- sutet_duri.png            (foto proyek SUTET Duri Kosambi)
- fabrikasi.png             (foto fabrikasi cable bridge)
- dapur_catering.png        (foto proyek dapur catering)
- Elektrifikasi_SKTM.png    (foto proyek elektrifikasi SKTM)
- jembatan_sumbawa.jpg      (foto instalasi jembatan Sumbawa)
- jembatan_meas.jpg         (foto instalasi jembatan MEAS)
- langsir_material.png      (foto logistik material via helikopter)
- delta_mas.png             (foto proyek Delta Mas)
- blue_bird.png             (foto proyek Blue Bird)
- squarted.png              (foto proyek Squarted)
- water_tes.png             (foto water test Padma Hotel)

Silakan salin/upload semua file foto Anda ke dalam folder "images/" ini
dengan nama yang PERSIS sama seperti daftar di atas, lalu file ini
(README.txt) boleh dihapus.

Jika salah satu gambar tidak ada, halaman tetap tampil tapi bagian
gambar tersebut akan kosong/rusak (ikon broken image).
